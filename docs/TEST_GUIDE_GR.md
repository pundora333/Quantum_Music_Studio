# Επαλήθευση Quantum Music Studio 1.7.2

Η πλήρης καταγεγραμμένη εκτέλεση της 21/10/2026 πέρασε **94 JavaScript και
41 Python ελέγχους**, χωρίς αποτυχίες ή παραλείψεις. Οι 41 περιλαμβάνουν
36 ελέγχους εφαρμογής και πέντε της δευτερογενούς ανάλυσης NMR.
Τα αρχεία καταγραφής και το πεδίο ελέγχου βρίσκονται στο
`research/circuit_2026-10-21/`. Η αλλαγή συσκευασίας/τεκμηρίωσης δεν αλλάζει
τον εκτελέσιμο κώδικα και δεν δηλώνεται ως νέα εκτέλεση αυτών των δοκιμών.

## Επανάληψη από τη ρίζα του repository

Χρησιμοποιήθηκαν Python 3.12 και Node.js 24. Δημιούργησε εικονικό περιβάλλον
Python και χρησιμοποίησε τον δικό του διερμηνευτή:

```sh
python -m pip install -r requirements-lock.txt
npm --prefix web ci
npm --prefix web test
python -m pytest python/tests research/test_parras_analysis.py -q
```

Η εκτέλεση μόνο του `python/tests` δεν περιλαμβάνει τους πέντε ελέγχους
δευτερογενούς ανάλυσης. Το `.github/workflows/ci.yml` εκτελεί όλες τις ομάδες
και εγκαθιστά FFmpeg για τους σχετικούς ελέγχους MP3. Οι απαιτούμενες
εξαρτήσεις cross-language/DOM πρέπει να είναι διαθέσιμες. Πιθανές παραλείψεις
αναφέρονται χωριστά από τις επιτυχίες.

## Επιστημονικά παραδείγματα

```sh
python research/analyse_parras.py
python run_studio.py render --session examples/Minimal_Circuit_Session.json --out reproduced/minimal --mp3
python run_studio.py render --session examples/Hahn_Echo_Session.json --out reproduced/echo --mp3
```

Η αναπαραγωγή της ανάλυσης μπορεί να ξαναγράψει τα αποτελέσματά της· κράτησε
χωριστό αντίγραφο για σύγκριση. Τα raw/PSD δεδομένα διακρίνονται και η μία
μήτρα δεν αντιστοιχίζεται αυθαίρετα σε κάποια από τις 39 συνοπτικές εγγραφές.
Στις ελεγχόμενες συγκρίσεις διατηρούνται κοινά session, seed, basis, mapping,
κούρδισμα, διάρκεια και gain, εκτός από τον δηλωμένο μεταβαλλόμενο παράγοντα.

Ο έλεγχος περιλαμβάνει πύλες, σειρά qubits, αναλυτικές αποσβέσεις, θετικότητα,
Hahn echo, σύγκλιση, ήχο, εξαγωγές, UI και σύνδεση πραγματικού τοπικού server.
Ο καταγεγραμμένος έλεγχος Chrome αφορά υπολογιστή. Δεν είναι μελέτη ακροατών,
νέο πείραμα NMR, έλεγχος φυσικού κινητού ή πλήρης πιστοποίηση προσβασιμότητας.
