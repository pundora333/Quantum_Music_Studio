# Πρόσθετη μεθοδολογία της έκδοσης Python

Το Quantum Music Studio υλοποιήθηκε αρχικά ως εφαρμογή HTML, CSS και JavaScript.
Η έκδοση έρευνας 1.0.0 προσθέτει τοπικό υπολογιστικό πυρήνα Python, διατηρώντας την
ίδια διεπαφή μουσικού πειραματισμού. Το Qiskit χρησιμοποιείται για προετοιμασία
Statevector, DensityMatrix, μοναδιαίες πύλες και κανάλια Kraus. Η NumPy χειρίζεται
τους πίνακες και τη Fourier ανάλυση, η SciPy τη δυναμική ανοικτού συστήματος,
η Matplotlib τα στατικά σχήματα και η lameenc τη συμπίεση MP3. Δεν χρησιμοποιείται
Qiskit Aer, πραγματικό QPU ή υπηρεσία IBM. Η αριθμητική προσομοίωση απαιτεί μόνο
δύο qubits και μήτρα πυκνότητας 4 × 4.

Στη δημόσια σημειογραφία του studio το q0 είναι το αριστερό bit στη βάση
|q0 q1> = {|00>, |01>, |10>, |11>}. Επειδή το Qiskit τοποθετεί το wire 0 στο
λιγότερο σημαντικό bit, το studio q0 αντιστοιχίζεται στο Qiskit wire 1 και το
studio q1 στο wire 0. Οι πίνακες και οι έξοδοι διατηρούν έτσι τη σειρά της
αρχικής εφαρμογής. Η αντιστοίχιση ελέγχεται για τις πύλες και τις δύο κατευθύνσεις
CNOT. Οι παράμετροι των καθαρών καταστάσεων είναι σε radians στο API Music,
ενώ οι γωνίες του NMR schema είναι σε degrees και μετατρέπονται πριν την πύλη.

Για την καθαρή προετοιμασία κατασκευάζεται QuantumCircuit με Ry και P σε κάθε
qubit και προαιρετική CNOT. Οι X, Y, Z βάσεις υλοποιούνται με τους αντίστοιχους
μετασχηματισμούς πριν τον κανόνα Born. Οι δειγματοληψίες αντιπροσωπεύουν
ανεξάρτητες προετοιμασίες. Για επανάληψη του ίδιου 16-step take χρησιμοποιείται
ο ίδιος Mulberry32 seed generator της JavaScript. Η concurrence υπολογίζεται
σταθερά ως C = 2|a00 a11 − a01 a10| πάνω στο καθαρό Qiskit Statevector.
Ο τύπος δεν εφαρμόζεται στο μεικτό φυσικό NMR ensemble.

Το NMR mode χρησιμοποιεί ρ = (1−ε)I4/4 + ερeff με ε = 10⁻⁵, ενδεικτική ασθενή
πόλωση, και το abstract mode χρησιμοποιεί απευθείας ρeff. Το Hamiltonian στο
περιστρεφόμενο πλαίσιο είναι H/ℏ = π(ν0 Z0 + ν1 Z1 + J Z0Z1/2). Οι ν και J
δίνονται σε Hz. Δεν είναι ακουστικές συχνότητες ούτε οι πλήρεις RF Larmor
συχνότητες. Για κάθε spin τίθενται οι τελεστές κατάρρευσης
L− = √[(1+zeq)/(2T1)] σ−, L+ = √[(1−zeq)/(2T1)] σ+ και
Lφ = √[γφ/2] Z, με γφ = 1/T2 − 1/(2T1), T2 ≤ 2T1 και χρόνους σε seconds.
Στη βάση αυτή σ− = |0><1|. Στο abstract mode zeq=1 και στο NMR mode zeq=ε.

Η εξίσωση Lindblad είναι dρ/dt = −i[H/ℏ,ρ] + Σk(LkρLk† − {Lk†Lk,ρ}/2).
Με column-major διανυσματοποίηση ο τελεστής εξέλιξης είναι exp(ℒΔt), όπου ℒ
έχει διαστάσεις 16 × 16. Η scipy.linalg.expm αξιολογεί αριθμητικά αυτήν την
εκθετική. Ο χαρακτηρισμός «ακριβής λύση σταθερού generator» αφορά τη μαθηματική
μορφή exp(ℒΔt), όχι απουσία floating-point σφάλματος. Η αρχική JavaScript
χρησιμοποιεί συμμετρικό splitting Hamiltonian και τοπικών καναλιών, οπότε η
σύγκριση ελέγχει σύγκλιση και όχι απαίτηση ταύτισης όλων των bit.

Η στατική Gaussian διασπορά offsets εφαρμόζεται κατά το acquisition όπως στην
αρχική έκδοση. σ = √(1−T2*/T2)/(√2 π T2*) και
E(t)=exp[−t/T2−2π²σ²t²]. Έτσι E(T2*)=1/e. Με ιδανικούς π παλμούς και στα δύο
spins στο τ, ο στατικός όρος χρησιμοποιεί διαδρομή t πριν τον παλμό και 2τ−t
μετά. Στο 2τ παραμένει η μη αντιστρέψιμη T2 απώλεια. Το JZZ δεν αντιστρέφεται
από την ταυτόχρονη αντιστροφή και των δύο Z. Η διασπορά δεν εισάγεται ως
πρόσθετος Lindblad ρυθμός ούτε ως δεύτερη εκθετική απόσβεση.

Το FID ανακατασκευάζεται από τις τέσσερις conditional coherences της ρ,
με S0=2(ρ20+ρ31), S1=2(ρ10+ρ32), επί τον στατικό παράγοντα και, μόνο για την
οπτική/ακουστική αναφορά NMR, επί 1/ε. Η φυσική μήτρα παραμένει κανονικοποιημένη.
Στο JSON/CSV διατηρούνται πραγματικό και φανταστικό μέρος. Η FFT είναι FFT του
complex FID με ρητή σύμβαση προσήμου. Ένα σήμα ensemble δεν παρέχει από μόνο
του πλήρη tomography ή ένα bitstring κάθε μορίου.

Στην τοπική εφαρμογή ο stdlib HTTP server δέχεται μόνο loopback και ελέγχει
Host/Origin. Η διεπαφή εκτελεί ασύγχρονες κλήσεις προς τον υπολογιστή του χρήστη
και απορρίπτει παλιά αποτελέσματα όταν έχουν αλλάξει οι παράμετροι. Web Audio,
ακουστική αναπαραγωγή και interactive canvas παραμένουν στον browser. Οι αλλαγές
σύνδεσης εφαρμόζονται στη μνήμη από frontend.py· το αποθηκευμένο web snapshot
παραμένει αμετάβλητο. Η CLI δίνει δεύτερη οδό εξαγωγής χωρίς browser.

Στην Python η ανασύνθεση ήχου χρησιμοποιεί τα ίδια carriers και envelopes,
γραμμική παρεμβολή του φυσικού χρόνου σε επιλεγμένη ακουστική διάρκεια, seed,
στερεοφωνική δρομολόγηση, attack/release και bounded gain. WAV είναι PCM 16-bit,
44,1 kHz, stereo· MP3 είναι 128 kbps με lameenc. Η συμπίεση MP3 δεν αναμένεται
να δώσει byte-identical αρχείο με lamejs. Η δημιουργική παραμόρφωση αποτελεί
ηχητική επεξεργασία, όχι επιπλέον φυσικό κανάλι. Η φυσική διάρκεια W και η
ακουστική διάρκεια D δηλώνονται χωριστά.

Η επαλήθευση της 1.7.2 καταγράφεται στο research/circuit_2026-10-21/ και στα tests.
Στις 21/10/2026 πέρασαν 94 έλεγχοι JavaScript και 41 Python, χωρίς αποτυχίες ή
παραλείψεις· οι πέντε έλεγχοι δευτερογενούς ανάλυσης περιλαμβάνονται στους 41.
Το research/validation_report.json διατηρεί τα ιστορικά αριθμητικά benchmarks
της 1.0.0 με την αρχική ημερομηνία τους. Ελέγχθηκαν αναλυτικοί νόμοι, πυκνότητες, σύγκλιση,
παραδείγματα FID, μουσικές βάσεις, επανάληψη shots, ήχος και πραγματικός HTTP
server με jsdom. Δεν εκτελέστηκε πείραμα σε QPU ή με ακροατές. Η εγκατάσταση
και εκτέλεση δοκιμάστηκαν σε Linux/Python 3.12· οι Windows εντολές παρέχονται
χωρίς να παρουσιάζονται ως ανεξάρτητη δοκιμή σε Windows.
