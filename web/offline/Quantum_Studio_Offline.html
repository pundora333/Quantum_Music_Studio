UNDER THE INSTRUMENT

What is quantum here?

The state model. The probabilities. The correlations.
The audible signal is classical.

State preparation & measurement

Starting from |00⟩, each qubit is prepared as cos(θ/2)|0⟩ + exp(iφ) sin(θ/2)|1⟩ using Ry(θ), then P(φ). The preparation CNOT uses q0 as control and q1 as target. The added two-wire editor supports ordered H, X, Y, Z, S, T, Rx/Ry/Rz and CNOT gates. Gates act on the prepared state; inspection previews do not insert projective measurements.

For basis B, pₖ = |⟨bₖ|ψ⟩|². X measurement uses H before computational readout; Y uses S† then H. Outcome bit 0 means the +1 eigenvalue of the selected Pauli operator; bit 1 means −1. The joint state remains the prepared state between independent shots.

Entanglement, phase & what you can hear

For a normalized pure state, concurrence is C = 2|a₀₀a₁₁ − a₀₁a₁₀|. C = 0 means a product state, and C = 1 means maximal entanglement. Local Bloch vectors come from reduced density matrices. Relative phase can change X/Y probabilities even when Z probabilities stay unchanged.

A sampled note alone cannot certify entanglement. Two states can produce the same probabilities in a chosen basis. No quantum advantage, quantum hardware, or effect on consciousness is claimed.

Sonification, tuning & comparison

Measured melody samples the exact probabilities using a seeded classical pseudorandom generator. Each measurement assumes fresh preparation. The probability chord assigns amplitude √pₖ, normalized by Σ√pₖ, to each mapped oscillator. This deterministic sonification uses full simulated probabilities, not a single quantum measurement. Quantum amplitude phases are not directly used as audio oscillator phases.

12-TET uses f = f₀ × 2ⁿ⁄¹². Just intonation uses chosen rational frequency ratios relative to f₀; our palette is 1, 16/15, 9/8, 6/5, 5/4, 4/3, 45/32, 3/2, 8/5, 5/3, 9/5, 15/8, 2. Custom mode uses f = f₀ × 2ᶜ⁄¹²⁰⁰. Δ = 1200 log₂(f/f₁₂₋TET) cents. JI intervals are reference-dependent; this does not claim all intervals between all notes are pure.

A/B freezes all settings and repeats the same 16 outcomes. In probability-chord mode, both halves repeat the same chord rhythm. Edits stop an A/B comparison so its conditions remain controlled.

Privacy, reproducibility & sources

The hosted edition uses restricted access; this offline file runs locally. There are no analytics, external fonts, audio uploads, or quantum-provider calls. State calculations, sound and session storage run in your browser. Saved sessions stay in this browser's local storage; exported JSON contains the parameters, exact state amplitudes, probabilities, seed, outcomes and tuning frequencies.

Web Audio is enabled by a user gesture. If your browser or device interrupts audio, stop and press Play again. Start with a comfortable device volume.
